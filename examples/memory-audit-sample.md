# Synthetic Memory Audit

This example is fictional. It demonstrates the audit format without publishing a real learner's memory.

## Audit summary

| Claim | Type | Status | Evidence | Review | Consumers | Action |
|---|---|---|---|---|---|---|
| Learner is preparing for an analytics interview on 2026-09-15 | Explicit goal | Confirmed | User statement in session A | 2026-09-16 | weekly-review, interview | Keep until interview passes |
| Learner avoids applied artifacts | Behavioural inference | Candidate | Sessions A and C; session B is only a summary of A | Not eligible: only 2 independent episodes | None while candidate | Seek confirmation only after another independent episode |
| Retrieval reminders should include a concrete deadline | Intervention | Confirmed | Approved after reproduced missed-retrieval defect | Review after 3 uses | weekly-review | Evaluate outcomes |
| Learner prefers diagrams | Explicit preference | Disputed | Old onboarding statement contradicted in session D | Now | learn, lab | Stop using; correct or retire |

## Candidate review

**System belief:** The learner may avoid producing applied artifacts.

**Why:** Two independent sessions ended after study with no artifact. A weekly review repeated the first event but does not count as a third episode.

**Current effect:** None. Candidate memories do not change tutor behaviour.

**Learner controls:** Confirm, dispute, correct, or leave as a candidate. If confirmed later, set an expiry date and name the intervention separately.

## Effect log excerpt

| Date | Memory | Consumer | Decision or intervention | Result | Evidence / follow-up |
|---|---|---|---|---|---|
| 2026-08-10 | retrieval-deadline-intervention | weekly-review | Assigned one retrieval task with a date | helpful | Task completed before next review |
| 2026-08-17 | prefers-diagrams | learn | Added an unnecessary diagram | irrelevant | Learner asked for a short written example instead |

## Audit actions

1. Keep the explicit interview goal until its stated horizon.
2. Do not promote the artifact-avoidance candidate yet.
3. Continue evaluating the retrieval intervention after material uses.
4. Stop applying the disputed diagram preference and ask whether to correct, retire, or delete it.
